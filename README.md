# speedy

A private Rust TUI that records how many keys you press each day and reports activity analytics.

Opening `speedy` starts one background recorder and displays the live dashboard. Closing the
dashboard with `q` or `Esc` does not stop recording. Run `speedy --stop` when you want to stop
the background recorder.
